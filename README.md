#🎬 Movie Explorer

A modern and responsive **Country Explorer** web application built with **React.js**, **Tailwind CSS**, and a country data API.

Explore countries around the world, search by country name, filter by region, view detailed information, check local time, and explore locations through a clean and user-friendly interface.

---

## ✨ Features

* 🔎 **Search Countries** — Search countries by name
* 🌎 **Explore Countries** — Browse countries from around the world
* 🗺️ **Region Filter** — Filter countries by continent or region
* 📍 **Location Support** — Select or detect your location
* 🕐 **Local Time** — View local time information
* 📊 **Country Details** — Explore detailed country information
* 🌙 **Dark Mode** — Switch between light and dark themes
* 📱 **Fully Responsive** — Works smoothly on mobile, tablet, and desktop
* ⚡ **Modern UI** — Clean design with smooth interactions

## 🔍 How to Use

### 🔎 Search

Use the search bar to find a specific country by name.

### 🗺️ Filter

Use the region filter to browse countries based on their geographical region.

### 📊 View Details

Select a country to view more detailed information such as:

* Country name
* Flag
* Capital
* Region
* Population
* Timezone



### 📍 Location

Use the location feature to select or detect your current location and explore relevant country information.

### 🌙 Dark Mode

Use the theme toggle to switch between **Light Mode** and **Dark Mode**.
